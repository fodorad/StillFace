.. py:function:: stack_vertical(top: pathlib.Path, bottom: pathlib.Path, dst: pathlib.Path, audio_source: int = 1) -> bool

   Stack two videos on top of each other.

   :param top: Video placed on top.
   :param bottom: Video placed below.
   :param dst: Output video. An existing file is kept.
   :param audio_source: 0 to keep the audio of ``top``, 1 for ``bottom``.

   :returns: True if the output exists afterwards.


.. py:function:: stack_grid(videos: dict[str, pathlib.Path | None], dst: pathlib.Path, audio_source: str = 'baby') -> bool

   Arrange the cameras in a 2x2 grid, replacing missing ones with black.

   :param videos: Camera name mapped to video path, or None if unavailable.
   :param dst: Output video. An existing file is kept.
   :param audio_source: Camera providing the audio; falls back by :data:`AUDIO_PRIORITY`.

   :returns: True if the output exists afterwards.
