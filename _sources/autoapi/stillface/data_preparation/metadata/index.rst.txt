.. py:function:: load_metadata(path: pathlib.Path) -> pandas.DataFrame

   Load the session metadata table.

   :param path: Spreadsheet (``.xlsx``) or ``.csv`` file.

   :returns: One row per session.

   :raises FileNotFoundError: If ``path`` does not exist.
   :raises ValueError: If the file type is not supported.

   :returns: One row per missing recording with ``ID``, session date, hour and a description.
