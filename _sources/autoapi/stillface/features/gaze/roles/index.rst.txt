stillface.features.gaze.roles
=============================

.. py:module:: stillface.features.gaze.roles

.. autoapi-nested-parse::

   Deciding which head track is the mother and which is the baby.

   Close cameras show one person, so the dominant track belongs to the camera's owner. The
   side cameras show both participants in profile at fixed positions (mother on the right in
   the window camera, on the left in the door camera) plus occasional background people. In
   the baseline phase the positions may change, so size and face identity decide there.

   Assign head tracks to the mother and the baby.

   :param tracks: Head tracks of the clip.
   :param camera: Camera name.
   :param phase: Experiment phase.
   :param n_frames: Number of sampled frames in the clip.
   :param config: Gaze configuration (side priors, role rules).

   :returns: The assignment; people that cannot be assigned are None.

.. py:function:: camera_persons(camera: str) -> tuple[str, ...]

   People whose gaze a camera can show.

   :param camera: Camera name.

   :returns: Both people for the side cameras, only the camera's owner for the close cameras.


.. py:function:: missing_reason(camera: str, person: str) -> str

   Why a person has no head on a frame.

   The mother's face is regularly hidden by the baby camera in the door view; elsewhere a
   missing head is just not found.

   :param camera: Camera name.
   :param person: ``mother`` or ``baby``.

   :returns: ``occluded`` or ``no_head``.


.. py:function:: load_role_overrides(path: pathlib.Path) -> RoleOverrides

   Read a per-session ``roles.json``.

   The file maps camera, phase and person to a track id, e.g.
   ``{"window": {"play": {"mother": 3, "baby": 1}}}``.

   :param path: File to read; a missing file means no overrides.

   :returns: The overrides, empty if the file does not exist.

   :raises ValueError: If the file names an unknown camera, phase or person, or a non-integer
       track id.
