stillface.features.gaze.classes
===============================

.. py:module:: stillface.features.gaze.classes

.. autoapi-nested-parse::

   From gaze heatmaps to the plan's gaze target classes.

   Classes follow the manual coding scheme: for the baby (T1) ANYARA (at the mother),
   TARGY_KORNYEZET (at an object or the environment), ELFORDUL (turned away); for the mother
   (T6) BABARA (at the baby) and MASHOVA (elsewhere); NK if not codable.

.. py:function:: mass_in_box(heatmap: numpy.ndarray, box: stillface.features.gaze.heads.HeadBox) -> float

   Share of a heatmap's mass inside a normalized box.

   Cells that the box covers partially count proportionally, so the result is 1 for the
   whole image and never shrinks when the box grows.

   :param heatmap: Gaze map of shape ``(height, width)``.
   :param box: Region in normalized image coordinates.

   :returns: Value in [0, 1]; 0 if the heatmap is empty.


.. py:function:: gaze_point(heatmap: numpy.ndarray) -> tuple[float, float]

   :returns: Normalized ``(x, y)`` of the peak cell center.


.. py:function:: classify(person: str, camera: str, heatmap: numpy.ndarray, inout: float | None, partner_box: stillface.features.gaze.heads.HeadBox | None, config: stillface.features.gaze.config.GazeConfig) -> GazeDecision

   Turn one person's gaze heatmap into a target class.

   Side cameras see the partner, so looking at the partner means heatmap mass inside the
   partner's (enlarged) head box. A close camera does not see the partner; there the
   calibrated partner zone of that camera takes its place.

   :param person: ``mother`` or ``baby``, the looker.
   :param camera: Camera the frame comes from.
   :param heatmap: Gaze map of shape ``(height, width)``.
   :param inout: Probability that the target is inside the frame, None if unavailable.
   :param partner_box: Head box of the partner on side cameras, None if not found.
   :param config: Thresholds, margins and partner zones.

   :returns: The decision with the supporting values.

   :raises ValueError: If ``person`` or ``camera`` is unknown.
