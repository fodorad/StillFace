stillface.features.gaze.pilot
=============================

.. py:module:: stillface.features.gaze.pilot

.. autoapi-nested-parse::

   Head pilot: heads, roles and overlays without any gaze model.

   The pilot validates the detection, tracking and role assignment on chosen sessions before
   the gaze model is run. It writes the same timeline format as the gaze pipeline, with empty
   gaze fields, plus overlay clips showing the heads and their roles.

.. py:function:: run_heads(paths: stillface.config.DatasetPaths, session_id: str, tracker: stillface.features.gaze.heads.HeadTracker, config: stillface.features.gaze.config.GazeConfig, cameras: collections.abc.Sequence[str] = CAMERAS, phases: collections.abc.Sequence[str] = PHASES, overlay: bool = True, overwrite: bool = False) -> stillface.features.run_record.RunRecord

   Run the head pilot on the clips of one session.

   Per clip a timeline CSV and (optionally) an overlay clip are written; per phase a
   stacked overlay grid. Existing outputs are kept unless ``overwrite``. A failing clip is
   recorded in the run record and does not stop the others.

   :param paths: Dataset locations.
   :param session_id: Session identifier.
   :param tracker: Head detector and tracker.
   :param config: Gaze configuration.
   :param cameras: Cameras to process.
   :param phases: Phases to process.
   :param overlay: Also render overlay clips and grids.
   :param overwrite: Recompute existing outputs.

   :returns: The run record, also written to ``run.json`` in the pilot folder.
