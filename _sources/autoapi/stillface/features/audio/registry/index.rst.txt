.. py:function:: build_adapter(name: str, config: stillface.features.audio.config.AudioConfig, root: pathlib.Path | None = None) -> stillface.features.audio.models.ModelAdapter

   Create the adapter of a configured model.

   :param name: Model name, a key of ``config.models``.
   :param config: Audio configuration.
   :param root: Folder of the model environments; from :data:`ENVS_VAR` if None.

   :returns: A subprocess adapter, or the registered in-process adapter for models without ``env``.

   :raises ValueError: If the model is unknown or has no runner.
