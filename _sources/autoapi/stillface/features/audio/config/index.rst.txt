stillface.features.audio.config
===============================

.. py:module:: stillface.features.audio.config

.. autoapi-nested-parse::

   Configuration of the audio pipeline.

   Every source choice, threshold and rule lives here, never in the code; the resolved config
   is copied into each run record and its hash into every provenance sidecar.

Module Contents

.. py:data:: CONFIG_VERSION
   :type:  int
   :value: 1


   Supported version of the audio config file format.

.. py:data:: DEFAULT_CONFIG_PATH
   :type:  pathlib.Path

   Config file shipped with the package.

.. py:class:: SourceConfig

   Which microphone feeds the pipeline.

   .. attribute:: cameras

      Camera clips tried in order; the first with a decodable audio stream wins.
      The baby-cam phone lies next to the mother's head and hears both partners.
      Early sessions with two window camcorders try the baby-facing ``window_2``
      before ``window_1``.


.. py:class:: ScopeConfig

   Which sessions are analysed.

   .. attribute:: analysis_column

      Metadata column flagging analysed sessions.

   .. attribute:: exclude

      Session ids left out although flagged (e.g. the first visit of a dyad).


.. py:class:: InventoryConfig

   Level statistics of the inventory.

   .. attribute:: frame_s

      Frame length for the near-silence share.

   .. attribute:: silence_dbfs

      Frame RMS below this level counts as near-silent.

   .. attribute:: clip_level

      Absolute sample value at or above which a sample counts as clipped.


.. py:class:: PrepareConfig

   Prepared analysis audio.

   .. attribute:: sample_rate

      Output sample rate; every model reads 16 kHz mono.


.. py:class:: RolesConfig

   Who is who: VTC voice types to roles, and the mother's voice enrolment.

   .. attribute:: vtc_model

      Model whose segments give the voice types.

   .. attribute:: embedding_model

      Model whose segment embeddings identify the mother.

   .. attribute:: baby_labels

      VTC classes that are the baby (no siblings: key child and other child).

   .. attribute:: enrol_phase

      Phase whose female speech enrols the mother's voice.

   .. attribute:: fallback_phase

      Phase used when the enrolment phase has too little speech.

   .. attribute:: enrol_total_s

      Longest female segments are used up to this total.

   .. attribute:: enrol_min_s

      Less enrolment speech than this leaves the session unresolved.

   .. attribute:: tau_high

      Cosine similarity at or above which a female segment is the mother.

   .. attribute:: tau_low

      Cosine similarity at or below which it is another woman.


.. py:class:: ModelConfig

   How one model is run.

   .. attribute:: env

      Environment folder below ``$STILLFACE_AUDIO_ENVS``; empty for in-process models.

   .. attribute:: module

      Worker module run inside the environment.

   .. attribute:: weights_revision

      Exact weights revision (e.g. a Hugging Face commit hash).

   .. attribute:: worker_version

      Version of the worker code; bump it when its output changes.

   .. attribute:: device

      Preferred device (``mps``, ``cuda``, ``cpu``); workers fall back to CPU.

   .. attribute:: timeout_s

      Wall-clock limit of one batch.

   .. attribute:: window_s

      Analysis window for windowed models, 0 if not applicable.

   .. attribute:: hop_s

      Hop between windows, 0 if not applicable.

   .. attribute:: options

      Further model-specific options, passed to the worker as text.

   .. attribute:: input

      ``wav`` for whole-phase models (first pass), ``segments`` for models that
      score role segments (second pass).

   .. attribute:: enabled

      False keeps a configured model out of every run (recorded as disabled),
      e.g. until its outputs are verified.

   .. attribute:: segment_source

      For ``segments`` models, where the segments come from:
      ``vtc:<labels>`` (VTC segments with these classes, e.g. ``vtc:FEM,MAL``) or
      ``roles:<roles>`` (role segments, e.g. ``roles:mother,baby``) or ``asr:<track>``
      (one segment per transcribed utterance of a gated track, for the aligner).


   .. py:property:: digest
      :type: str


      Short SHA-256 of these settings; a change recomputes only this model's outputs.


.. py:class:: Threshold

   A documented threshold.

   .. attribute:: value

      Inclusive threshold on a score.

   .. attribute:: origin

      ``vendor`` (the model's published default), ``probe`` (our 3-session probe)
      or ``config`` (placeholder set here); see
      :data:`stillface.features.audio.lanes.ORIGINS`.


.. py:class:: TypeRule

   Model classes that vote for one vocalisation type.

   .. attribute:: ast

      AudioSet class names (AST).

   .. attribute:: littlebeats

      LittleBeats head classes.


.. py:class:: GongConfig

   Phase-boundary gong detection.

   .. attribute:: classes

      AudioSet classes counted as the gong.

   .. attribute:: edge_s

      Only the first and last ``edge_s`` seconds of a phase are searched.

   .. attribute:: dilate_s

      The detected gong is widened by this much on both sides.


.. py:class:: ContextConfig

   Non-vocal context sounds to flag.

   .. attribute:: classes

      AudioSet classes summarised per phase.

   .. attribute:: listen_share

      A class present at least this share of a phase sends the session to
      the listening list.


.. py:data:: DEFAULT_THRESHOLDS
   :type:  dict[str, Threshold]

   Fusion thresholds used when the config file names none (same as the shipped file).

.. py:class:: FusionConfig

   Rule-based fusion of the model outputs.

   .. attribute:: thresholds

      Named thresholds (``silero``, ``pyannote``, ``ast_type``, ``littlebeats``,
      ``gong``, ``context``).

   .. attribute:: gong

      Gong detection.

   .. attribute:: context

      Context flags.

   .. attribute:: baby_types

      Baby vocalisation type mapped to its voting classes.

   .. attribute:: mother_types

      Mother vocalisation type mapped to its AST classes; ``speech`` is the
      default when none reaches the threshold.

   .. attribute:: disagreement_listen_share

      VAD disagreement share of a phase that sends it to the
      listening list.


   .. py:method:: threshold(name: str) -> Threshold

      A named threshold.

      :param name: Threshold name.

      :returns: The threshold.

      :raises KeyError: If it is not configured.



.. py:class:: GatingConfig

   Mother-only and baby-only tracks.

   .. attribute:: pad_s

      Each role segment is widened by this much on both sides before gating, so
      word onsets and offsets survive.


.. py:class:: AffectConfig

   Affect lanes.

   .. attribute:: baby_valence_weights

      Weight of each baby type probability in the derived valence
      (``valence = sum(weight * p(type))``, clipped to ``[-1, 1]``).

   .. attribute:: baby_arousal_features

      Features averaged (after within-session min-max scaling) into
      the derived baby arousal: ``intensity``, ``f0`` and ``cry``.

   .. attribute:: min_agreement_frames

      Fewest shared frames needed for a model agreement value.


.. py:class:: AudioConfig

   Audio pipeline configuration.

   .. attribute:: version

      Config file format version.

   .. attribute:: source

      Microphone choice.

   .. attribute:: scope

      Session selection.

   .. attribute:: inventory

      Inventory statistics.

   .. attribute:: prepare

      Prepared audio format.

   .. attribute:: models

      Model name mapped to how it is run.

   .. attribute:: roles

      Role assignment settings.

   .. attribute:: fusion

      Fusion rules and thresholds.

   .. attribute:: gating

      Gated track settings.

   .. attribute:: affect

      Affect lane settings.


   .. py:property:: digest
      :type: str


      Short SHA-256 of the resolved configuration, recorded in provenance sidecars.


.. py:function:: load_audio_config(path: pathlib.Path = DEFAULT_CONFIG_PATH) -> AudioConfig

   Load and validate an audio config file.

   :param path: TOML file; the packaged defaults if omitted.

   :returns: The configuration.
