stillface.features.audio.lanes
==============================

.. py:module:: stillface.features.audio.lanes

.. autoapi-nested-parse::

   Lanes, bands and events: the one data model of the audio pipeline.

   Every audio signal is stored twice on a common phase-local grid (seconds from the start of
   the phase clip, :data:`GRID_RATE_HZ`):

   - a **lane**: the raw continuous value of one quantity from one source, with a fixed range,
     NaN where it does not apply (e.g. mother affect outside mother segments);
   - a **band**: a boolean presence derived from a lane by a documented threshold or rule.

   Bands become **events** (maximal runs with optional merging and a minimum duration). Lanes
   and bands are written as one wide CSV per phase, events as a long CSV, and the metadata of
   both as a legend JSON, so a table can always be traced back to the rule that produced it.

.. py:function:: to_grid(times: numpy.ndarray, values: numpy.ndarray, duration_s: float, spec: LaneSpec, rate_hz: float = GRID_RATE_HZ, hold_s: float = 0.0) -> Lane

   Resample native-rate samples onto the lane grid.

   Bin ``k`` collects the samples with ``round(t * rate_hz) == k``. Samples outside the
   phase and NaN samples are ignored; empty bins are NaN unless a sample lies within
   ``hold_s`` of the bin time, whose value is then held (for sources slower than the grid,
   e.g. AST windows every 0.25 s).

   :param times: Sample times in seconds, phase-local.
   :param values: Sample values; category indices for majority lanes.
   :param duration_s: Phase duration.
   :param spec: Lane description, its aggregation is applied.
   :param rate_hz: Grid rate.
   :param hold_s: Largest distance to the nearest sample for filling an empty bin.

   :returns: The lane.

.. py:function:: band_to_events(band: Band, role: str, label: str, source: str, confidence: Lane | None = None, merge_gap_s: float = 0.0, min_duration_s: float = 0.0, rate_hz: float = GRID_RATE_HZ) -> list[Event]

   Turn a band into events.

   Runs separated by at most ``merge_gap_s`` are merged first, then runs shorter than
   ``min_duration_s`` are dropped. An event of a run covering bins ``a … b-1`` spans
   ``[a / rate, b / rate)``.

   :param band: Presence band.
   :param role: Role of the events.
   :param label: Label of the events.
   :param source: Producing model or stage.
   :param confidence: Lane whose mean over the run is the confidence (clipped to [0, 1]);
                      confidence 1 if None or all NaN.
   :param merge_gap_s: Largest gap that is bridged.
   :param min_duration_s: Shortest kept event.
   :param rate_hz: Grid rate.

   :returns: Events in time order.
