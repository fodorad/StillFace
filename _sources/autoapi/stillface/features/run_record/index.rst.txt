.. py:class:: RunRecord

   Provenance of one extraction run over a session.

   .. attribute:: session_id

      Session identifier.

   .. attribute:: model_variant

      Model that produced the signals (``none`` for the head pilot).

   .. attribute:: config

      Copy of the configuration used.

   .. attribute:: exordium_version

      Installed exordium version, None if not installed.

   .. attribute:: stillface_version

      Installed StillFace version.

   .. attribute:: git_sha

      Commit of the StillFace checkout, None outside a git repository.

   .. attribute:: clips

      Names of the processed clips.

   .. attribute:: flags

      Issue name mapped to the affected items, e.g. ``roles_ambiguous`` or ``failed``.
