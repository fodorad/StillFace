stillface.config
================

.. py:module:: stillface.config

.. autoapi-nested-parse::

   Dataset locations.

   The ``data/`` folder of a checkout holds soft links to the unmodified recordings
   (``DB``) and to the derived products (``DB_PROCESSED``). Raw data is only read,
   every generated file is written below the processed root.

   .. py:method:: phase_clip(session_id: str, camera: str, phase: str) -> pathlib.Path

      Path of a camera's clip of one phase in the original dataset (read-only).

      These per-camera, per-phase clips are the input of every feature extractor.

      :param session_id: Session identifier.
      :param camera: One of :data:`stillface.constants.CAMERAS`.
      :param phase: One of :data:`stillface.constants.PHASES`.

      :returns: Path of ``<camera>_<phase>.mp4``; the file may not exist.

      :raises ValueError: If ``camera`` or ``phase`` is unknown.



   .. py:method:: available_phase_clips(session_id: str) -> dict[tuple[str, str], pathlib.Path]

      Find the existing phase clips of a session.

      :param session_id: Session identifier.

      :returns: ``(camera, phase)`` mapped to the clip path. Missing clips are logged and omitted.
