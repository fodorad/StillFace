stillface.config
================

.. py:module:: stillface.config

.. autoapi-nested-parse::

   Dataset locations.

   The ``data/`` folder of a checkout holds soft links to the unmodified recordings
   (``DB``) and to the derived products (``DB_PROCESSED``). Raw data is only read,
   every generated file is written below the processed root.

.. py:class:: DatasetPaths

   Resolves every dataset location from a raw and a processed root.

   .. attribute:: raw_dir

      Directory of the original, untouched recordings and metadata.

   .. attribute:: processed_dir

      Directory receiving all derived data.


   .. py:method:: default(base: pathlib.Path = Path('data')) -> DatasetPaths
      :classmethod:


      Build paths from the environment, falling back to ``base``/DB[_PROCESSED].

      :param base: Folder holding the ``DB`` and ``DB_PROCESSED`` links.

      :returns: Resolved dataset paths.



   .. py:property:: metadata_path
      :type: pathlib.Path


      Session metadata spreadsheet.


   .. py:method:: original_dir(session_id: str) -> pathlib.Path

      Original recordings of a session (read-only).

      Original sources converted to a common container and frame rate.



   .. py:method:: synced_dir(session_id: str) -> pathlib.Path

      Time-aligned camera videos.



   .. py:method:: cut_dir(session_id: str) -> pathlib.Path

   .. py:method:: visualize_dir(session_id: str) -> pathlib.Path

      Stacked overview videos.



   .. py:method:: thumbnail_path(session_id: str) -> pathlib.Path
