stillface.features.audio.models¶

Model adapters: one interface for every model of the audio pipeline.

A model adapter turns a batch of InferenceRequest (a prepared WAV, optionally with segments to score) into one InferenceResult or InferenceError per request. Heavy models run in their own environments as worker processes (SubprocessAdapter), light ones in-process; the stages never know which.

This module is imported by the worker processes too, so it depends on nothing but the standard library and numpy.
