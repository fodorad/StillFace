stillface.features.audio.lanes¶

Lanes, bands and events: the one data model of the audio pipeline.

Every audio signal is stored twice on a common phase-local grid (seconds from the start of the phase clip, GRID_RATE_HZ):

  • a lane: the raw continuous value of one quantity from one source, with a fixed range, NaN where it does not apply (e.g. mother affect outside mother segments);

  • a band: a boolean presence derived from a lane by a documented threshold or rule.

Bands become events (maximal runs with optional merging and a minimum duration). Lanes and bands are written as one wide CSV per phase, events as a long CSV, and the metadata of both as a legend JSON, so a table can always be traced back to the rule that produced it.

Resample native-rate samples onto the lane grid.

Bin k collects the samples with round(t * rate_hz) == k. Samples outside the phase and NaN samples are ignored; empty bins are NaN.

  • values – Sample values; category indices for majority lanes.

  • duration_s – Phase duration.

  • spec – Lane description, its aggregation is applied.

  • rate_hz – Grid rate.

stillface.features.audio.lanes.band_to_events(band: Band, role: str, label: str, source: str, confidence: Lane | None = None, merge_gap_s: float = 0.0, min_duration_s: float = 0.0, rate_hz: float = GRID_RATE_HZ) → list[Event][source]¶

Turn a band into events.

Runs separated by at most merge_gap_s are merged first, then runs shorter than min_duration_s are dropped. An event of a run covering bins a … b-1 spans [a / rate, b / rate).

Parameters:

  • band – Presence band.

  • role – Role of the events.

  • label – Label of the events.

  • source – Producing model or stage.

  • confidence – Lane whose mean over the run is the confidence (clipped to [0, 1]); confidence 1 if None or all NaN.

  • merge_gap_s – Largest gap that is bridged.

  • min_duration_s – Shortest kept event.

  • rate_hz – Grid rate.

Returns:

Events in time order.
