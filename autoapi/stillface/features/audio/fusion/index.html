stillface.features.audio.fusion¶

Rule-based fusion: every model output on one grid, plus the fused decisions.

For one session phase the fusion stage reads the raw outputs of the first- and second-pass models and the role events, and writes:

  • lanes/<phase>.csv + lanes/<phase>.json: every raw score as a lane (10 Hz) and every presence decision as a band, each band with its threshold, origin and rule id;

  • events/<phase>.csv: fused vocalisation events (baby type per baby segment, mother type per mother segment, addressee per adult segment);

  • fusion/<phase>.json: phase summary (context shares, disagreement share, which models were available).

All rules are listed by id in RULES and their thresholds come from the config, so decisions can render the exact decision tables that produced the data. No rule is learned; learned fusion needs annotations (later phase).
