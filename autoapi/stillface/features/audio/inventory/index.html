stillface.features.audio.inventory¶

Session inventory: which microphone each session and phase has, and in what state.

The inventory is the first audio stage. It reads nothing but the phase clips and the metadata sheet, picks one source clip per session and phase by the configured fallback order, and records the audio format and level problems, so the later stages and the user know what to expect before any model runs.

Attributes¶

logger

STATUSES

Inventory status of a session phase, from usable to unusable.

FALSY_FLAGS

Metadata flag values read as False (case-insensitive); anything else is True.

INVENTORY_COLUMNS
