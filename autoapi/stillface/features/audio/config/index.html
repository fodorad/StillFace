stillface.features.audio.config¶

Configuration of the audio pipeline.

Every source choice, threshold and rule lives here, never in the code; the resolved config is copied into each run record and its hash into every provenance sidecar.

Attributes¶

Supported version of the audio config file format.

DEFAULT_CONFIG_PATH

Config file shipped with the package.

class stillface.features.audio.config.SourceConfig[source]¶

Which microphone feeds the pipeline.

cameras¶

Camera clips tried in order; the first with a decodable audio stream wins. The baby-cam phone lies next to the mother’s head and hears both partners.

class stillface.features.audio.config.ScopeConfig[source]¶

Which sessions are analysed.

analysis_column¶

Metadata column flagging analysed sessions.

exclude¶

Session ids left out although flagged (e.g. the first visit of a dyad).

class stillface.features.audio.config.InventoryConfig[source]¶

Level statistics of the inventory.

frame_s¶

Frame length for the near-silence share.

silence_dbfs¶

Frame RMS below this level counts as near-silent.

clip_level¶

Absolute sample value at or above which a sample counts as clipped.

class stillface.features.audio.config.PrepareConfig[source]¶

Prepared analysis audio.

sample_rate¶

Output sample rate; every model reads 16 kHz mono.

class stillface.features.audio.config.RolesConfig[source]¶

Who is who: VTC voice types to roles, and the mother’s voice enrolment.

vtc_model¶

Model whose segments give the voice types.

embedding_model¶

Model whose segment embeddings identify the mother.

baby_labels¶

VTC classes that are the baby (no siblings: key child and other child).

enrol_phase¶

Phase whose female speech enrols the mother’s voice.

fallback_phase¶

Phase used when the enrolment phase has too little speech.

enrol_total_s¶

Longest female segments are used up to this total.

enrol_min_s¶

Less enrolment speech than this leaves the session unresolved.

tau_high¶

Cosine similarity at or above which a female segment is the mother.

tau_low¶

Cosine similarity at or below which it is another woman.

class stillface.features.audio.config.ModelConfig[source]¶

How one model is run.

env¶

Environment folder below $STILLFACE_AUDIO_ENVS; empty for in-process models.

module¶

Worker module run inside the environment.

weights_revision¶

Exact weights revision (e.g. a Hugging Face commit hash).

worker_version¶

Version of the worker code; bump it when its output changes.

device¶

Preferred device (mps, cuda, cpu); workers fall back to CPU.

timeout_s¶

Wall-clock limit of one batch.

window_s¶

Analysis window for windowed models, 0 if not applicable.

hop_s¶

Hop between windows, 0 if not applicable.

options¶

Further model-specific options, passed to the worker as text.

input¶

wav for whole-phase models (first pass), segments for models that score role segments (second pass).

enabled¶

False keeps a configured model out of every run (recorded as disabled), e.g. until its outputs are verified.

segment_source¶

For segments models, where the segments come from: vtc:<labels> (VTC segments with these classes, e.g. vtc:FEM,MAL) or roles:<roles> (role segments, e.g. roles:mother,baby) or asr:<track> (one segment per transcribed utterance of a gated track, for the aligner).

property digest: str¶

Short SHA-256 of these settings; a change recomputes only this model’s outputs.

class stillface.features.audio.config.Threshold[source]¶

A documented threshold.

value¶

Inclusive threshold on a score.

origin¶

vendor (the model’s published default), probe (our 3-session probe) or config (placeholder set here); see stillface.features.audio.lanes.ORIGINS.

class stillface.features.audio.config.TypeRule[source]¶

Model classes that vote for one vocalisation type.

ast¶

AudioSet class names (AST).

littlebeats¶

LittleBeats head classes.

class stillface.features.audio.config.GongConfig[source]¶

Phase-boundary gong detection.

classes¶

AudioSet classes counted as the gong.

edge_s¶

Only the first and last edge_s seconds of a phase are searched.

dilate_s¶

The detected gong is widened by this much on both sides.

class stillface.features.audio.config.ContextConfig[source]¶

Non-vocal context sounds to flag.

classes¶

AudioSet classes summarised per phase.

listen_share¶

A class present at least this share of a phase sends the session to the listening list.

class stillface.features.audio.config.FusionConfig[source]¶

Rule-based fusion of the model outputs.

thresholds¶

Named thresholds (silero, pyannote, ast_type, littlebeats, gong, context).

gong¶

Gong detection.

context¶

Context flags.

baby_types¶

Baby vocalisation type mapped to its voting classes.

mother_types¶

Mother vocalisation type mapped to its AST classes; speech is the default when none reaches the threshold.

disagreement_listen_share¶

VAD disagreement share of a phase that sends it to the listening list.

class stillface.features.audio.config.GatingConfig[source]¶

Mother-only and baby-only tracks.

pad_s¶

Each role segment is widened by this much on both sides before gating, so word onsets and offsets survive.
