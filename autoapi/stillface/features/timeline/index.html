stillface.features.timeline¶

Frame-wise feature timelines and their CSV format.

All feature extractors write the same long format: one row per sampled frame and person. Times are phase-local, i.e. seconds from the start of the phase clip, so they stay consistent with the cut and stacked overview videos.

COLUMNS

Timeline CSV columns, in file order.

Session identifier.

Camera name.

phase¶

Experiment phase.

frame_index¶

Index of the frame in the phase clip.

time_s¶

Phase-local time, frame_index / clip_fps.

person¶

mother or baby.

gaze_x¶

Gaze target x in normalized image coordinates, None if not codable.

gaze_y¶

Gaze target y in normalized image coordinates, None if not codable.

inout¶

Probability that the gaze target is inside the frame, None if not codable.

partner_mass¶

Share of the gaze heatmap on the partner (head box or zone).

gaze_class¶

Target class from the plan codes, NK if not codable.

reason¶

Why the row is not codable (occluded, no_head, …), else empty.

face_visible¶

Whether the face was detected inside the head box on this frame (the frame-wise usability mask for face-based analyses), None if there is no head.

stillface.features.timeline.sample_frame_indices(n_frames: int, clip_fps: float, sample_rate_hz: float) → list[int][source]¶

Choose the frames of a clip that lie on a regular time grid.

Parameters:

  • n_frames – Number of frames in the clip.

  • clip_fps – Frame rate of the clip.

  • sample_rate_hz – Requested sampling rate, at most clip_fps.

Returns:

Ascending, unique frame indices. At 30 Hz on a 60 fps clip every second frame.

Raises:

ValueError – If sample_rate_hz exceeds clip_fps.
