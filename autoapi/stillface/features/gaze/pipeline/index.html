stillface.features.gaze.pipeline.read_frames(clip: pathlib.Path, frame_indices: collections.abc.Sequence[int]) → collections.abc.Iterator[numpy.ndarray][source]¶

Stream selected frames of a clip.

Parameters:

  • clip – Video file.

  • frame_indices – Ascending frame indices to return.

Yields:

RGB uint8 frames of shape (height, width, 3), in the order of the indices. The stream ends early if the clip has fewer decodable frames than its metadata claims (decoders disagree by a frame on real clips); callers must handle that.

Raises:

RuntimeError – If the clip cannot be read.

  • camera – Camera name.

  • phase – Experiment phase.

  • prepared – Heads of the clip.

  • decisions – (sample position, person) mapped to the decision; people without a head on a frame are not codable.

Returns:

Rows and overlay items of every sampled frame.

stillface.features.gaze.pipeline.run_gaze(paths: stillface.config.DatasetPaths, session_id: str, tracker: stillface.features.gaze.heads.HeadTracker, estimator: stillface.features.gaze.estimator.GazeEstimator, config: stillface.features.gaze.config.GazeConfig, cameras: collections.abc.Sequence[str] = CAMERAS, phases: collections.abc.Sequence[str] = PHASES, overlay: bool = True, overwrite: bool = False, batch_size: int = 8) → stillface.features.run_record.RunRecord[source]¶

Extract the gaze of the mother and the baby for one session.

Per clip a timeline CSV and (optionally) an overlay clip are written; per phase a stacked overlay grid; per session run.json records the model variant used. See run_session() for the resume and failure behaviour.

Parameters:

  • paths – Dataset locations.

  • session_id – Session identifier.

  • tracker – Head detector and tracker.

  • estimator – Gaze target model.

  • config – Gaze configuration.

  • cameras – Cameras to process.

  • phases – Phases to process.

  • overlay – Also render overlay clips and grids.

  • overwrite – Recompute existing outputs.

  • batch_size – Frames per model call.

Returns:

The run record, also written to run.json in the gaze folder.
