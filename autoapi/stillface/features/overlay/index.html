stillface.features.overlay¶

Overlay videos: extracted features drawn onto the camera clips.

An overlay clip has the resolution, frame rate and frame count of its source clip, drops the audio, and shows the annotations of the last sampled frame until the next one (sample and hold). The overlays of the four cameras can be stacked into the same 2x2 grid as the overview videos.

class stillface.features.overlay.OverlayItem[source]¶

What is drawn for one person on one frame.

person¶

mother or baby.

box¶

Head box in normalized coordinates, None if no head was found.

gaze¶

Gaze target in normalized coordinates, None if there is none (pilot mode or not codable).

label¶

Text after the role, e.g. the gaze class; labels starting with NK are drawn as not codable.

stillface.features.overlay.render_overlay(clip: pathlib.Path, items_by_frame: collections.abc.Mapping[int, collections.abc.Sequence[OverlayItem]], dst: pathlib.Path, overwrite: bool = False) → None[source]¶

Render an overlay clip.

Parameters:

  • clip – Source clip.

  • items_by_frame – Sampled frame index mapped to the annotations from that frame on.

  • dst – Output .mp4. An existing file is kept unless overwrite.

  • overwrite – Render even if dst exists.

Raises:

RuntimeError – If the clip cannot be read or ffmpeg fails.

stillface.features.overlay.render_overlay_grid(overlays: collections.abc.Mapping[str, pathlib.Path | None], dst: pathlib.Path, overwrite: bool = False) → bool[source]¶

Stack the camera overlays into the 2x2 overview layout.

Mother is top-left, window top-right, baby bottom-left, door bottom-right; missing cameras are black.

Parameters:

  • overlays – Camera name mapped to its overlay clip, or None.

  • dst – Output .mp4. An existing file is kept unless overwrite.

  • overwrite – Render even if dst exists.

Returns:

True if the grid exists afterwards.
